# Agent skills

Coding guidelines for AI assistants working on this repository, taken from
[skills.sh](https://skills.sh). Each folder keeps its original MIT license.

| Skill | Source | Used for |
|---|---|---|
| `rust-best-practices` | [apollographql/skills](https://github.com/apollographql/skills) | `crates/` |
| `swiftui-pro` | [twostraws/swiftui-agent-skill](https://github.com/twostraws/swiftui-agent-skill) | `macos/Sources/Diskbloom` |
| `swift-concurrency` | [AvdLee/swift-concurrency-agent-skill](https://github.com/AvdLee/swift-concurrency-agent-skill) | async code, Swift 6 mode |

Project-specific rules (deployment target, localization, safety) are in
[CONTRIBUTING.md](../../CONTRIBUTING.md) and take precedence.
